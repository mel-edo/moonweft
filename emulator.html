Moonweft Game Boy Emulator

Welcome to my custom Game Boy emulator, entirely built in Rust and compiled to WebAssembly!

Controls:

  • D-Pad: Arrow Keys
  • A: X
  • B: Z
  • Start: Enter
  • Select: Backspace
  • Fast Forward: Hold Shift

Click "Insert Cartridge" above the Game Boy to load a .gb or .dmg ROM file and start playing.
